    How it works

    One morning, from the first window to the standup line. Same data at every step.

    What happens What it looks like inside

    1. Sees

      Which window is in front, and when you step away. App name and title; no keystrokes, no screenshots, no clipboard.

      Calls, calendar, ticket keys, the folder a terminal is in: noted beside each stretch. Hands off the keyboard is quiet, not away: the stretch stays open until the screen locks, or ten minutes pass with nothing live, thirty with a page, a call or an agent in front of you.

    2. Places

      Every minute, plain rules: a ticket key in a branch or a tab, the project folder, a window you filed before. Provisional, marked to confirm.

      When the batch closes, the local model reads a short digest and places the rest. Eight blocks at most, about two minutes on a laptop CPU.

      Two windows in turn over one stretch split the time by share, never counted twice. A second placer that scores the evidence per window sits behind a switch in Settings. Minutes it was not running are written down as not captured, never guessed.

    3. Learns

      It will be wrong sometimes. Rename a task, its project with it; move or throw out a block; the correction is kept with the window it was made in and read first next time. Thrown out is a hard no.

      Loose time folds into runs you file in one go, task pre-filled. Once a day, slivers tidy into their neighbours; one undo.

    4. Writes

      Standup, timeline, task cards, reports, chat. One table; nothing worked out twice, nothing stored anywhere else.

    5. Shows its work

      Settings keeps the pipeline in view: the model loaded, the worker, batches waiting, the last batch with its tokens. Two buttons: the digest the model read, the answer it gave.

    6. Your own key, if you want

      Local until you paste an API key. Then pick what goes out: writing and chat, or everything. Two dollars a day, then local. The key sits in one file only you can read.

      Storage & server keeps one line that says what left the machine today. With no key it ends in “nothing else”.
