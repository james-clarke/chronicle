Your day, your work, as it happened.

Focus events get grouped into blocks. Each block is matched to a task you declared, or to one Chronicle inferred.

Every task, one card.

Open any block for its summary, every session that went into it, and where the time went. Ask about it, rename it, close it.

Ask your own history.

Connect the tools you already use.

Link your ticket tracker and your project folders. A ticket number in a window title becomes a task with its real name and context attached.

How it works

Chronicle is built close to the operating system, in Rust, with no browser engine and no server. Every step below happens on your machine.

  1. 1

    Capture

    A small background process notices which window is in front and when you step away. Any app counts: browser, documents, mail, design tools, terminal.

    Native OS hooks · X11 today, macOS Accessibility and Win32 events next · idle detection

  2. 2

    Derive

    A language model running inside the app groups that activity into tasks and writes a plain-English line for each one.

    Qwen3 1.7B, embedded via llama.cpp · runs on CPU · downloaded once, then offline

  3. 3

    Correct

    Move a block, rename a task, merge two that are really one. Every correction feeds the next pass, so it gets better at reading your day.

    Corrections stored as anchors · the next derivation reads them

  4. 4

    Use

    Standup draft each morning, a weekly report, a card per task, and a chat that answers from your own history.

    Standup, reports and chat all read the same local database

Native, not a web page in a box

One binary written in Rust. No Electron, no web view, no runtime to install.

The model lives in the app

Inference runs in-process on your CPU. No API key, no usage meter, no waiting on someone else's server.

Your history is one file

A SQLite database in your home folder with full-text search built in. Back it up, move it, or delete it. It's yours.

Nothing phones home

No account, no sync, no telemetry, no crash reports. The only network calls are to connections you add yourself.
