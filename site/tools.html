What it reads.

Every tool Chronicle knows about, supported or not. A planned row is a tool people have and Chronicle cannot read yet; the number beside it is the open request. This table is the same registry the app's Settings › Connections and chronicle connections render, committed from the source tree.

Missing something you work with? In the app, Settings › Connections › What you work with lists the tools it saw you use and could not read, each with a request button that opens a prefilled issue in your browser. Or file one by hand.
