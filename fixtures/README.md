# Fixtures: the cast

Every name in `fixtures/`, in the tests that read them, and in the site's
screenshots is invented. This is the cast, so that a new fixture extends the
same story instead of starting another one.

## Acme

A small software company. Its Jira is `acme.atlassian.net`, its work-item
keys are `ACME-…`, its GitHub organisation is `acme`, and its API lives under
`acmeapi.example`.

- **Contoso** is Acme's product, a memberships platform: the `contoso`
  repository (Django).
- **mailer** is the messaging service beside it, the `mailer` repository,
  with a staging host at `staging-mailer.acmeapi.example` and an RDS
  instance called `mailerdb-staging`.
- **Northwind** is Acme's largest customer. Its deployments are the Heroku
  apps `northwind-memberships` (production), `northwind-qa` and
  `northwind-test`, with a Slack channel per environment.

People at Acme:

- **Sam**, a backend developer. Shell prompt `sam@workstation`. The site's
  screenshots are Sam's week.
- **Jordan Lee**, Sam's product manager, `jordan@acme.com`. `pm_day.jsonl`
  is one of Jordan's days.
- **Priya** and **Tomasz**, the other two developers on the platform team,
  seen through their pull requests.

## The studio

`agency_day.jsonl` is a different person: a freelance designer at a two-person
studio, `jordan@studio.co`, whose clients are called Northwind and Contoso.
The names are shared with Acme's on purpose (the project matcher has to cope
with the same word meaning a customer in one config and a repository in
another) but the people are not.

## The days

| File | Whose | What happens |
|---|---|---|
| `day1.jsonl`, `day2_web.jsonl` | Sam | Short baseline days for the sessionizer goldens. |
| `day3_sms.jsonl`, `day4_heroku.jsonl` | Sam | Two long days chasing failing SMS sends through `mailer`, RDS and Northwind's Heroku apps. Golden spans and digests sit beside them. |
| `dead_x.jsonl` | Sam | A capture that lost its display. |
| `pm_day.jsonl` | Jordan | A product manager's day: roadmap, customer calls, Jira. |
| `agency_day.jsonl` | the studio | Brand work for Northwind, a site for Contoso, timesheets. |
| `site/mon.jsonl` … `site/fri.jsonl` | Sam | The week of 7–11 September 2026, generated by `scripts/site_week.py`. `ACME-11381` (retry backoff in `mailer`) lands on Tuesday, `ACME-11382` (renewal reminder emails in `contoso`) is the week's main work, `ACME-11390` is Wednesday's Northwind firefight, `ACME-11374` is the staging deploy pipeline in the gaps. |

`site/config.toml` is the project configuration those five days are filed
under, and `scripts/site-shots.sh` is what replays them into a sandbox
database and takes the site's screenshots.

## Adding a fixture

Extend the cast rather than inventing beside it: a new customer is another
Northwind-sized name, a new repository belongs to Acme, a new person works
with Sam or Jordan. Never a real host, key, machine name or person.
